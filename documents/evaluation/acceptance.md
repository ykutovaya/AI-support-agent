# Проверка приложения

Если приложение уже открыто и слева есть три обращения — **«Обычный обмен», «Изменение цены», «Передача специалисту»** — переходите к проверкам. Новое обращение создавать не нужно. Завершённый сценарий повторять не нужно.

## Запуск

В терминале **PowerShell** выполните:

```powershell
Set-Location 'C:\Users\USER\Documents\portfolio\ai-support-agent'
if (-not (Test-Path 'var/ui-acceptance.sqlite3')) {
    .\var\runtime\Scripts\python.exe evals/ui-readability/prepare_acceptance.py --db var/ui-acceptance.sqlite3
}
$env:SUPPORT_AGENT_MODE = 'demo'
$env:SUPPORT_AGENT_RECOVERY_MODE = 'manual'
$env:SUPPORT_AGENT_TICKET_BACKEND = 'local'
$env:SUPPORT_AGENT_RETAIL_DB = 'evals/reapproval/base_shop.json'
$env:SUPPORT_AGENT_DB = 'var/ui-acceptance.sqlite3'
.\var\runtime\Scripts\python.exe -m streamlit run src/support_agent/ui.py --server.address 127.0.0.1 --server.port 8501 --server.headless true --browser.gatherUsageStats false
```

Откройте **[http://127.0.0.1:8501](http://127.0.0.1:8501)**. Терминал оставьте открытым. Существующая база сохраняется. Если порт занят, второй сервер не запускайте: остановите прежний через `Ctrl+C` в его терминале. Если не найден `python.exe`, выполните [установку из README](../../README.md#запуск-рабочего-места).

Дальше все действия выполняются **в браузере**.

## 1. Обычный обмен

1. Слева в **«Открыть обращение»** выберите **«Обычный обмен · exchange@example.test»**.
2. В **«Новое сообщение клиента»** вставьте `Обменяйте товар. Email exchange@example.test` и нажмите **«Подготовить решение»**.
3. Справа проверьте доплату **2.35 USD** и нажмите **«Подтвердить отправку»**.
4. В появившемся поле **«Текст ответа клиента»** напишите `Согласен с указанными условиями`. Щёлкните вне поля и нажмите **«Клиент согласен»**.
5. В карточке **«Действие и ответ»** проверьте **2.35 USD** и нажмите **«Подтвердить действие и ответ»**.

**Ожидается:** статус `exchange requested`, одна операция и две доставки в истории — условия и итог. Заявка специалисту не создаётся.

Кнопки «Клиент согласен» нет до отправки условий; она недоступна, пока не заполнен текст ответа.

## 2. Изменение цены

Здесь прежнее согласие клиента и изменение цены подготовлены заранее. Новое сообщение вводить и цену менять не нужно.

1. Слева выберите **«Изменение цены · price@example.test»**.
2. Нажмите **«Подтвердить действие и ответ»** при старой доплате **2.35 USD**. Должна появиться блокировка и изменение **2.35 → 9.99 USD**.
3. Нажмите **«Продолжить расследование»**. Появятся условия с доплатой **9.99 USD**.
4. Нажмите **«Подтвердить отправку»**.
5. В **«Текст ответа клиента»** введите `Согласен с доплатой 9.99 USD`. Щёлкните вне поля и нажмите **«Клиент согласен»**.
6. В новой карточке проверьте **9.99 USD** и нажмите **«Подтвердить действие и ответ»**.

**Ожидается:** статус `exchange requested`, одна операция и три доставки — старые условия, новые условия и итог. Если уже видите блокировку или новую сумму, продолжайте с соответствующего шага.

## 3. Передача специалисту

1. Слева выберите **«Передача специалисту · ticket@example.test»**.
2. В **«Новое сообщение клиента»** вставьте `Проверьте результат обмена. Email ticket@example.test` и нажмите **«Подготовить решение»**.
3. Проверьте тему и текст **«Локальной учебной заявки»**, затем нажмите **«Подтвердить действие и ответ»**. Согласие клиента здесь не требуется.

**Ожидается:** номер вида `T-1`, статус `open`, одна операция и одна доставка. Заказ не меняется; Zammad не используется.

## 4. Сохранение

1. Обновите страницу круговой стрелкой рядом с адресом браузера. Обращение, история и итог должны сохраниться.
2. Остановите сервер через `Ctrl+C` в терминале. Дождитесь строки для ввода команды, повторите блок запуска выше и обновите прежнюю вкладку браузера.
3. Проверьте, что история сохранилась и повторных сообщений нет. Имя базы не меняйте.

Напишите в чат результат каждого сценария или номер шага, где возникла проблема. Например: `Обмен — готово; цена — шаг 3, кнопки нет; заявку пока не проверяла.`
