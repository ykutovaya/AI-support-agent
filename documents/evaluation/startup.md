В частности, новое окружение содержит согласованные `uvicorn==0.54.0` и `websockets==17.4`; старые смешанные окружения не исправлялись и не переустанавливались.

Это копия указанного commit с изменениями установки; исходники приложения и тесты совпадают с проектом после нормализации переводов строк CRLF/LF. После проверки в самом проекте создано отдельное `var/runtime` тем же `uv sync`. Оно готово для команд ниже; старые `.venv` сохранены. Установка и совпадение исходников зафиксированы в [проверке окружения проекта](../../evals/startup/2026-10-31/project-environment.json). При сверке байтов исходников сначала обнаружены только различия CRLF/LF; после нормализации расхождений кода нет.

## Установка и запуск

Единственный путь установки полного рабочего места описан в [README](../../README.md#запуск-рабочего-места). В проверочной копии использован тот же `uv sync`, с отдельным абсолютным путём в `UV_PROJECT_ENVIRONMENT`. Для работы из корня проекта:

```powershell
$env:UV_PROJECT_ENVIRONMENT = 'var/runtime'
uv sync --locked --extra retail --extra dev --python 3.12.12
$env:SUPPORT_AGENT_MODE = 'demo'
$env:SUPPORT_AGENT_RECOVERY_MODE = 'manual'
$env:SUPPORT_AGENT_RETAIL_DB = 'evals/reapproval/base_shop.json'
$env:SUPPORT_AGENT_DB = 'var/demo.sqlite3'
.\var\runtime\Scripts\python.exe -m streamlit run src\support_agent\ui.py --server.address 127.0.0.1 --server.port 8501 --server.headless true --browser.gatherUsageStats false
```

Первая установка требует GitHub и источников пакетов. Первичная загрузка τ-bench заняла заметное время; это задержка установки, не ошибка приложения. Для остановки — `Ctrl+C`. Повторный запуск с тем же `SUPPORT_AGENT_DB` сохраняет историю. Чтобы начать заново, остановить сервер, задать ещё несуществующий файл, например `var/demo-next.sqlite3`, и повторить запуск. Старый файл сохраняется.

Магазин и соседний `policy.md` копируются только при первой инициализации SQLite. Для этого пути используется собственный синтетический магазин, а не полный набор задач τ-bench. Установленный пакет τ-bench не содержит корневого каталога данных: его предупреждение об отсутствии `Lib/data` не мешает явно заданному учебному снимку. Для штатных заданий нужен отдельный checkout закреплённой версии и `TAU2_DATA_DIR`; порядок указан в README.
