# Текст и счётчики отказов: проверка без API

Исправлены оценщик `investigation-v6`, контракт данных и метрики `interventions-v2`.
Это повтор известных текстов и проверки с подставными ответами, не новая оценка модели.

- `review.json` — два точных ответа из прежнего контроля: `review` до исправления, `pass` после. В исходных попытках они не доставлены.
- `validation.json` — версии, хеши кода, результаты проверок. Всего 290 различных успешных тестов; повторы не прибавлены.
- `historical-hashes.json` — 500 исходных файлов серий, оставшихся без изменений.
- `*-before.xml`, `*-red.xml` — проверки до исправлений; остальные XML — успешные проверки после них.

Данные исправлены отдельно: [набор v2](../control-new-2026-11-03-v2.json), [изменения и контракт](../control-new-2026-11-03-v2-card.md).
Ошибки структуры проверяются при загрузке. Правильность именных форм товара проверена примерами, а не универсальным анализатором языка.

Из корня проекта можно повторить основные проверки без ключей:

```powershell
.\var\runtime\Scripts\python.exe -m pytest tests/test_investigation_assessment.py tests/test_investigation_cases.py tests/test_investigation_runner.py tests/test_intervention_metrics.py -q
```

Тесты отключают загрузку `.env`; модель и внешние системы подставные. Отдельно проверены существующие потребители оценщика и метрик. Платных запросов и изменений приложения нет. Неизвестная формулировка остаётся `review`; неизвестная причина отзыва не считается отказом. Исторические **4/6** и `client_refusals=0` сохранены.
