# Два полных процесса без API

Использованы точные ответы из прежнего нового контроля и исправленный набор v2.
Остальные ответы модели и поведение клиента и сотрудника заданы заранее.
Режимы — `manual/local`; каждый случай начинается с отдельного учебного снимка.

| Случай | Результат | Операции / доставки |
|---|---|---:|
| Поиск по имени и индексу | Уточнение доставлено; после ответа клиента выполнен поиск `find_user_id_by_name_zip`, согласована доплата 9,50 USD, зарегистрирована заявка `exchange requested` | 1 / 3 |
| Отзыв согласия | Магазин не изменён; старое согласие отозвано, точный согласованный ответ об отказе доставлен | 0 / 2 |

Оба результата — `complete`, нарушений согласований не обнаружено. API-вызовов и расходов нет. Сеть запрещена; `.env` не читается. Это проверка процесса на заданных ответах, не новое измерение качества модели. Исходные `review` и **4/6** сохранены.

`manifest.json` фиксирует исходные тексты, версии и хеши кода; `summary.json` — итог и точные доставленные сообщения. В папках случаев сохранены сценарии, подставные вызовы, запросы ядра, события, состояние, решения сотрудника и результаты оценщика. SQLite остаются локальными и исключены из Git.

Повтор из корня проекта, с новым каталогом результата:

```powershell
.\var\runtime\Scripts\python.exe -m evals.investigation.check_known_replies --set name-zip-refusal --output evals/investigation/final-check-new
```

Без `--set` команда сохраняет прежний набор: уточнение email и отказ от обмена наушников.

Ограничение метрик этой записи: `interventions-v2` считает все согласия с `revoked=1`, включая использованное при успешном обмене. Поэтому у первого случая `client_consent_revocations=1` с неизвестной причиной; это не отказ клиента (`client_refusals=0`). У второго случая текстовый отказ связан с конкретным событием и отозванным согласием.

Исправление сохранено отдельно: [пересчёт `interventions-v3`](../metrics-v3.json). Подтверждённых клиентских отзывов — 0 при обмене и 1 при отказе. Общий флаг утраты силы согласия теперь учитывается в `consent_invalidations`; отсутствие связи с сообщением — в `consent_invalidations_unattributed`. Полнота клиентских отзывов ограничена сохранёнными аннотациями; у старых снимков без них счётчик равен `null`. Процессы не повторялись, исходные JSON этой папки не менялись.
