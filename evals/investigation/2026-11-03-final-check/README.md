# Итоговая техническая проверка

Без API, на подставных ответах через общее ядро и исполнитель, `manual/local`.

| Случай | Результат |
|---|---|
| Имя и индекс → обмен | `exchange requested`, 1 операция, 3 доставки |
| Отзыв согласия → ответ об отказе | `delivered`, 0 операций, 2 доставки |

- `flows/` — точные ответы, вызовы, согласования, состояния и результаты двух процессов. Ключи и локальные SQLite не публикуются.
- `metrics-v3.json` — отдельный пересчёт после обнаружения неточности v2: флаг `revoked` означает также использованное согласие. Подтверждённых отзывов клиента в обмене 0, в отказе 1; прочие причины не угадываются.
- `validation.json`, `version.json` — результаты и хеши проверенной версии.
- `pytest.xml` — полный набор: **720 passed**. `flows-*` и `consent-metrics-*` — проверки до и после исправлений. `consent-metrics-test-setup.xml` содержит ошибку подготовки теста, не приложения.
- `package-audit.json` — файлы установки, зависимости и ссылки. Новая чистая установка не проводилась.
- `github-actions.json` — успешный запуск прежнего коммита; незакоммиченная версия им не проверена.

Повторение из корня проекта в установленном окружении:

```powershell
.\var\runtime\Scripts\python.exe -m evals.investigation.check_known_replies --set name-zip-refusal --output evals/investigation/offline-final-new
.\var\runtime\Scripts\python.exe -m pytest
.\var\runtime\Scripts\python.exe -m ruff check .
```

Каталог результата должен быть новым. Исторические `review`, **4/6** и исходные метрики сохранены. Прохождение этих процессов не является новой оценкой настоящей модели или запуском другим человеком. Для закрытия этапа нужен GitHub Actions итогового опубликованного коммита.
